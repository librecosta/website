# E1 实验验收

源码 `2e710906e974c09777f3c7279744bbcada5404c9`，批次 `e1`，复拍批次 `e1-repeat`。交付 10 张 1600×900 PNG、18 张原始 WebGL 截图、数值数组和 600 组逐帧数据。F01–F03 与 F05–F10 通过各自检查。F04 成图，证据状态为 `limited`。每张图的来源、SHA-256、复现命令和原文件哈希见 [生成清单](outputs/e1/manifest.json)，详细测量见 [JSON 报告](outputs/e1/report.json)。

## F10 运行时性能

Windows 10 Home China x64 笔记本，Ryzen 7 5800H，Chrome Headless 157.0.8103.78，Three.js r187，WebGL 2.0（Chromium OpenGL ES 3.0），ANGLE Direct3D 11，实测 AMD Radeon 集成 GPU（设备 ID `0x1638`）。移动档使用同一台笔记本与同一 GPU 模拟触屏及视口。没有移动真机或其他显卡的实测。

固定滚动输入 0.35，相机约 `[-35.881, 52.206, -2180.931]` wu，天空为正式合成，沙尘输运和城市动画正常推进。每档三轮、各开新浏览器上下文，加载后再预热 45 帧，采样 100 帧，额外绘制 12 帧等 GPU 查询返回。GPU 计时由 `EXT_disjoint_timer_query_webgl2` 包围实际 `gl.render(scene, camera)`，剔除 disjoint 样本。本次 600 个 GPU 样本均有效。CPU 更新、独立纹理上传、浏览器合成和屏幕显示延迟不属于该 GPU 区间。帧间隔为相邻 `performance.now()` 渲染提交时间差，每档 3×99 条，不跨轮拼接。

## 工程验收

- `pnpm check:world` 与 `pnpm check` 通过。现行检查用 1,001 个离散位置验证镜头，最小地形与保守结构净空 21.270 和 382.159 wu；151 次窗口移动保留 2,758,784 个重叠格。最大质量账误差约 7.82×10⁻⁸ mg。
- `pnpm build:cn`、`pnpm build:intl` 与两区 `pnpm check:release` 通过。CN 导出 8 页、161 文件、18,502,731 B，INTL 导出 24 页、239 文件、19,303,335 B。产物路径与 HTML、JS、TXT 内容均检查过，无实验图、数据、入口或探针。
- 已浏览检查全部十张成图。作者审稿时建议重点看 F03 细沙纹在 CMS 缩图后的可读性，以及 F04 是否仍有独立保留价值。逐方位动态 GPU 性能和真实移动设备表现仍待后续测试。
