# BLOG-EXPANSE-E1

为 GopherAtlas 文章《从高度场到沙暴：LibreCosta 的程序化荒漠实践》取证。实验覆盖高度场和索引网格、沙纹与导数滤波、输沙浓度和移动窗口、近景沙暴、天空、空气透视以及渲染成本。只在 `develop` 维护实验，文章、封面与 CMS 发布由作者另行处理。

- 以当前 WORLD 源码为准。历史记录用来解释取舍，旧基准不参与当前统计。
- 离线在原函数上采样。浏览器以临时静态构建执行原渲染实现，仅加入记录、冻结时间和隔离所需开关。生产源码、参数、构建和公开路由保持原状。
- 截图在匹配的画布、机位、时间和渲染器下取样。保留未裁切的 Canvas PNG、运行条件、数值数组和逐帧计时。图表和裁图由脚本生成，并保留对应的原始文件与 SHA-256。
- 所有图为 1600 × 900 PNG，英文短标签与独立图注。证据薄弱时标 `limited`，捕获或验证失败时标 `blocked` 并保留原因。
- 身份区分以 [EVIDENCE.md](EVIDENCE.md) 为准。几何沙丘、表面法线、二维输运、程序化近景散射和天空色表各有独立的证据。移动配置是桌面模拟。
- 仅提交脚本、配置和文字；运行批次及发布选图位于 Git 忽略的 `outputs/`。图像与本文素材的使用边界见仓库 [ASSETS-LICENSE.md](../../../ASSETS-LICENSE.md)。
- 验收包括 `pnpm check:world`、`pnpm check`、CN / INTL 静态构建及发布检查，并核查生产产物没有实验入口、数据或图片。
