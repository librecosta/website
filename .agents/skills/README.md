# Repository GSAP Skills

This repository vendors five official GreenSock skills. The upstream skill files are kept intact.

| Skill | Use it for |
| --- | --- |
| [gsap-core](gsap-core/SKILL.md) | Tweens, easing, and animation fundamentals |
| [gsap-timeline](gsap-timeline/SKILL.md) | Sequencing and timing |
| [gsap-scrolltrigger](gsap-scrolltrigger/SKILL.md) | Scroll-driven progress and triggers |
| [gsap-react](gsap-react/SKILL.md) | React integration and cleanup |
| [gsap-performance](gsap-performance/SKILL.md) | Render and animation performance |

The skills are pinned to commit `aed9cfd3277740755f6bfc1155c7aa645403b760` and live under `.agents/skills/` for repository-local discovery. [GreenSock source](https://github.com/greensock/gsap-skills/tree/aed9cfd3277740755f6bfc1155c7aa645403b760)
