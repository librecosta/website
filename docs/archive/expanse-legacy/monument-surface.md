# 静默巨碑四面展开 · P1-C1A4-B2

此页记录已退役的静默巨碑表面研究。P1-F4 移除了旧碑、展开图页面与专用光场，图板和可编辑 SVG 的生成源码可在 Git 历史中的 `5910eb4` 查阅。

正背面共用 F，左右面共用 S。网格基宽、高、基深为 `920 × 1910 × 560`。四面按正、右、背、左展开，左面外缘折回正面。1 SVG 单位对应 1 场景单位。展开图按实际槽口裁切，底座与纵板之间的缩短段同时作用于网格和纹样。

| 图层 | 作用 |
| --- | --- |
| Panel | 浅暖矿物基底，纵板和同轮廓裁出的外围分段。 |
| Primary Lines | 贴合板边的金线与跨面端子。冠部徽记和底座承托徽记沿主槽对轴。 |
| Fine Lines | 两个分段节点与沿轴绕行的细纹。 |
| Emissive Mask | 分级控制纹刻亮度，可独立导出。 |

`layout.ts` 保存母版，`unwrap.ts` 从网格推导展开坐标，`artwork.ts` 输出 SVG。实景和三维预览共用 Atlas。纹刻近距离提亮，柔光限制在碑体表面，主槽两侧另有埋入内壁的窄灯带。底座位于沙下，可从完整三维预览或展开图查看。
