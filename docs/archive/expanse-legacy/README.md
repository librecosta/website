# The Expanse · 已退役的实验

P1-C1A4-Z1 博客素材。编号图片是 LibreCosta 自己的浏览器画面，经裁切、并排与 WebP 压缩，合计约 54 KiB。第二张为同机位对照，其余画面各自记录不同阶段的现象。原始实现可从下列提交回看。

| 案例 | 为什么退役 | 留下的经验 |
| --- | --- | --- |
| [旧调试面板与硬壳地形](01-retired-debug.webp) | 四面灰模下，两个材质菜单同时禁用，试材质必须先切回单槽。地表的逐阶段开关也能把已确认的沙丘几何和表面从场景里撤掉。更早的 P1-B2 冷灰硬壳遮罩虽可复现，却让浅谷碎成不同颜色的斑块。 | 调试面板现在直接检查当前场景。沙丘体积由迎风缓坡和背风陡坡建立，细纹随距离和采样密度衰减。历史版本见 `ffa581d` 与 `dfd2adf`。 |
| [单槽主碑的三代材质](02-monument-surface.webp) | 矿物候选把沉积、颗粒和粗糙度铺到整面，终点仍缺少能表达制造意图的结构。凹刻 B 将二维图形转成法线和遮蔽，斜线看起来像与真槽争夺注意力的第二道深切。平面迁移解决了浮雕感，但图稿围绕偏置单槽，没法准确避开四面居中的主槽和沿冠折返的辅槽。 | 当前灰模靠真实槽口、槽底和倒角读形。后续应以四面有效面域重画图形，再借用独立立方体已验证的面板、细线、掠射和发光分层。历史材质见 `ae4d423`、`e49490b`、`dc243e7`、`20721ed`。 |
| [薄霾逆光与孤立云带](03-light-and-sky.webp) | 逆光加厚薄霾、拉近雾距，碑体剪影更显眼，但槽和体块之间的反差被压低。J3D-R2 的离散云域在低仰角及较窄视口留下大片缺少组织的天空。 | 固定日照与云场分别解决各自的问题。侧光让槽壁和沙脊可读，连续的主云纱和支带共享世界方向，远碑取无云丝的空气色，避免云纹像叠在碑面上。逆光采自 `ffa581d`，孤立云带采自 `a28b188` 阶段留档。 |
| [移动地表密度与起沙诊断](04-sand-and-diagnostics.webp) | C0 的低频密度随风平移，形状不变，容易读成贴地明暗斑。后来的短沙迹虽然更可见，却像流光。风向箭头和橙色起沙遮罩用于验证模型输入，不能直接判断实际画面里的遮挡和浓淡。 | 用阈值起沙、平流、扩散与沉降驱动浓度变化。保留可见沙尘、浓度和关闭三档。源强仍在 CPU 模型和验证中，GPU 只上传当前两种可视化都用得到的浓度。 |

进一步的条件、测量及局限见 [程序化环境研究](../../research/procedural-environments.md) 和 [立方体表面研究](../../research/hubtown-cube-surface.md)。
