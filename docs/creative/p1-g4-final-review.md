**P1 — The Expanse / Content Frozen**

2026-11-13 在 `develop` 的 G4-B `448c544` 上验收 `/lab/expanse`。G1 建筑与巨构、[G2 材质与地表](p1-g2-final-review.md)、[G3 大气、光照与动态](p1-g3-final-review.md)、[G4-A 镜头](p1-g4-a-camera.md)和 [G4-B 字幕与品牌揭示](p1-g4-b-narrative.md)均达到内容集成条件。本轮提交验收记录，生产构建内容沿用 G4-B。正式首页迁移和部署验收由 WEB 阶段负责。

## 视觉

沿用 [G0 固定机位](p1-g0-visual-baseline.md)，在 1440×900 和模拟 390×844、DPR 1 下复拍 S0–S5。使用正常风沙、最终天空合成和中性指针偏移。

| 机位 | 验收结果 |
| --- | --- |
| S0 · 开场 | 暖色风幕保留遮蔽，天空高处的冷暖纹理、浅谷和远城剪影仍可区分。 |
| S1 · 浅谷 | 右坡风纹随坡面延伸，真实遗构投影贴合谷底。暗弧的边缘限制按 G3-B 已接受的质量边界保留。 |
| S2 · 遗构 | 信号塔倾斜轮廓、壳体及沙埋线可辨。遗构观测标记在镜头区间内可操作。 |
| S3 · 巨环 | 近侧主环、逆向副环、空港与停靠客运飞艇的前后关系可读，城市车流提供尺度参照。 |

## 叙事、交互与无障碍

- 慢速和快速滚动均观察到三段独白各触发、完整打印并移除一次。快滚时三段按顺序堆叠，立即回滚时各段仍能结束，前进重入时不重播。模拟页面隐藏时第一段停在原字符数，恢复后完整结束。
- 在 `p=.95 / u=.96829` 停到字幕清空，品牌三个元素透明度均为 0。先到终点等待字幕退场，或等字幕退场后再到终点，都会自动开始原揭示。品牌已揭示时终点前 1–2 CSS px 往返稳定，离开后收起并可在重入时再次揭示。逐帧记录中字幕与品牌没有重叠。
- 1440×900、1920×1080、390×844、320×568 和 1440×420 均捕获到三段完整堆叠。页面无横向溢出，字幕无内部滚动或裁切，顶部字标及底部进度线可见。打字内容由 `aria-hidden` 隔离，各段完成后才向 `role=status` 写入一次全文。隐藏品牌保持 `inert`。
- 原生滚动、PageDown 前进、Home 回到开场及平滑跟随通过。鼠标偏移可回正，模拟触控指针不引发镜头偏移。终景停留约 20 s 及回滚重入时城市时钟继续前进。多相位复查中主副环方向相反，客运飞艇随甲板、货运飞艇独立巡航。
- 五个观测标记均通过 Enter 打开、Escape 关闭并恢复焦点。390×844 额外复测了巨环观测卡。并行字幕复用一个 AudioContext，静音停止当前文字音效，后续字幕继续完成。三个调试音量滑块均可用方向键调节。
- 模拟 `prefers-reduced-motion` 匹配时场景停帧，实录保留三段独白、观测内容和品牌。模拟 WebGL2 不可用时 Canvas 卸载，“阅读本幕”可进入相同的 HTML 实录。

## 性能与资源

Windows、内置 Chromium 157、AMD Radeon 集成 GPU、ANGLE D3D11、WebGL2，关闭音频和观测卡。G4-B 基线与 G4-C 使用同一静态导出，57 个文件 SHA-256 一致，分别从两个本地源采样以观察同条件波动。桌面按 G4-B → G4-C、窄视口反序。每机位 6 s，GPU 计时覆盖该帧提交的 GL 工作，桌面每次 360 个样本，窄视口 180 个，全部无 disjoint。帧间隔取实际 R3F 渲染时间戳。

GPU P95 最大配对增幅为窄视口 S0 的 6.7%，低于 15% 复查线。帧间隔尾部仍有同构建波动。长期参考 G0 桌面 S0/S4 的 GPU P95 为 6.56/5.45 ms、24/22 Draw Calls，窄视口 GPU P95 为 2.04/2.01 ms。

- 首次 Canvas 可见单次采样，桌面 1,075 → 959 ms，窄视口 843 → 910 ms。无压缩、禁缓存的本地静态源实际启动传输约 2.41 MB，其中 12 个 JS 块 1,713,695 B、信号塔 GLB 644,896 B、CSS 与字体 26,322 B，排除采集脚本。声音关闭时无音频请求。正式部署的压缩、缓存与网络耗时需单独测量。
- 终景停留、回滚和刷新后 Geometry / Texture 稳定在 27 / 6。两轮路由退出均卸载 Canvas 并释放旧 WebGL 上下文，返回后驻留计数恢复。带巨环卡时为 28 / 7。卡片叠加字幕与单卡片两个短窗口的帧间隔分别为 16.7/33.3 和 16.7/33.4 ms，未观察到 ≥50 ms 主线程任务。逐字更新限于各字幕组件，卸载时回收其 GSAP 时间轴。
- 桌面和窄视口分别有 14 和 15 个 Shader 程序成功链接，含 `cityFinish`、`cityMark`、遗构与实例化程序，采样无 WebGL 错误。控制台仍有 Three.js 的 `Clock` 弃用警告。 `pnpm check` 通过世界约束、TypeScript 和静态构建。

## 冻结与集成边界

本轮未发现需要修复的内容缺陷。实机 iOS/Android、高 DPR、触控与实体触控板、手机横屏及系统后台恢复、系统屏幕阅读器未测。浏览器模拟覆盖了窄视口、可访问性语义和部分输入与可见性分支。

正式首页集成时保留原生可逆滚动与场景 sticky 区间的起止几何，保持单一相机写入者及现有终点停留区。品牌触发继续同时依赖原生终点、平滑镜头收束及字幕完成。保留五个观测点、Escape 焦点返回、全站单一音频引擎、减少动态效果及 HTML 实录回退。静态导出需保留场景模型、字体和音频的资源路径，并复查首页导航进出时 Canvas 与监听器的释放。
