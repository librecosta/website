## 生成记录

使用官方 [imagegen Skill](https://github.com/openai/skills/blob/main/skills/.system/imagegen/SKILL.md) 与内置 `image_gen.imagegen`。三版分别初始生成，随后针对环角过近、环面过于平行等问题修正；最终 B / C 分别以校正后的 A 为几何参照生成，控制梁体与材质差异。A 是本轮对照的工作基准，不代表用户已选定 A。

[prompts.json](prompts.json) 保存全部八次实际调用的完整 Prompt、输入关系和最终文件对应。`generation:<id>` 指向其中对应的中间生成；被替代中间图仍在 Codex 默认生成目录，未混入正式方案。最终三图及用户参考均已归档到本目录。

重建对照图：安装 Pillow 后运行 `python docs/creative/witness-core/r1-a2/compose_overview.py`。程序只缩小排版副本、加标签，保留原图；未增加网站依赖。

## 视觉验收与限制

已逐张实际查看最终三图，并查看程序对照图。三版均可辨认 **三个完整闭合方环 + 一个乳白立方光学内核**；各环使用矩形梁与一致的精密边缘语言，环面具有不同倾斜，未出现碎片、额外外壳、断环、文字或装饰性构件。内核保留面部明暗，无过曝光团或 Bloom；暗金属通过定向光显露厚度。

当前视图的环间空隙与前后关系可读，未见明显实体穿插。图像不是尺寸图，比例、截面尺寸、精确共心及各面是否严格为正方形仍需后续建模核对；**独立全角度转动尚未完成避碰验证**。C 近看仍有轻微规律性表面纹理，若选定 C，后续材质应进一步转为自然随机的氧化分布。
