# WORKS · 地图式艺术方向与交互契约

**WEB-V0.1-A0 · 供 A1 原型采用**

WORKS 是 LibreCosta 的虚构产品海图。平台共享一段可步行的岸线，系统位于内陆高低两处，视觉计算沿河口向外海延伸，出版物在港岛汇集。访客先看到这些关系，再通过地图上的小型设施打开单个作品的档案。已知道项目名的人可直接打开索引。

第一幕从明亮的荒原仰望巨构，WORKS 俯看深色海岸上的项目设施。两者共享克制的边缘、精确的比例和明确的留空。地图属于官网作品档案，独立于第一幕故事与后续章节设定。Hubtown 的参考点仅限从可探索空间进入项目面板。 [第一幕冻结记录](p1-g4-final-review.md) · [Hubtown Projects](https://hubtown.co.in/projects/)

## 地图构图

固定俯视，画幅 `1000 × 700`。一个向西南伸展的大陆占主体，东侧海域留给两处离岛。主陆北高、南低，东缘被海湾与三角洲切开。以海岸线、山脊、河谷和水域间隔划分区域。

| 区域 | 地貌与功能 |
| --- | --- |
| **Rivet Bight · 铆湾** | 西南内湾与低矮海岸平原。两处宽基座沿短路成对，表示同一受众的两个平台。海湾以西留出岸线。 |
| **Vane Divide · 风标岭** | 北部高地及山脊南坡的集水盆地。山脊承载观测塔，较低的盆地承载采集设施。两点之间有一条穿山短路，借高差读出不同角色。 |
| **Refraction Reach · 折光汊** | 大陆东岸的河口与向外延伸的半岛。一条河从风标岭南侧盆地出发，在低平处弯曲并于河口分成两汊。Liquid Glass 靠近水陆交界，Wavefield 位于开阔的沿海丘地。 |
| **Farbeat Isle · 远拍岛** | 东南独立离岛，岛脊低长，外侧有大片海面。Sofaraway 沿岛的长轴展开，以门架的间距表现节奏。 |
| **Folio Haven · 页港** | 东北独立港岛，港口向西南开口，背靠高台。GopherAtlas 面向主陆设档案塔，港湾外留出可供未来出版项目使用的岸段。 |

铆湾两平台之间为短路，铆湾内陆一侧到风标岭山口为长路，河口两点间用沿岸便道。海面只画一条稀疏虚线，从 Wavefield 海岸到页港，表示已有研究出版关系。路线不带箭头，不参与交互，也不表达软件依赖、托管位置或网络拓扑。离岛不铺通往所有节点的连接线。 [Wavefield 在 GopherAtlas 的技术文章](https://gopheratlas.com/notes/graphics-interaction/webgpu-wavefield-reconstruction/)

```text
       主陆高地与盆地                           外海
            Uptime                                GopherAtlas
                │                                 页港
              Harvest                              ╱
                 ╲ 河流                           ╱ 研究航线
                  ╲                 Wavefield ···
  GoFurry ─ Tool4Furry    Liquid Glass
       铆湾                  折光汊                   Sofaraway
                                                       远拍岛
```

海面保留连续暗底，海岸最多一层浅滩与一条细岸线。山脊用窄高地面和有限断续等高线，丘地用较宽的低对比坡面，盆地与平原保留大片安静的平面。河流从窄到宽，道路转弯服从地形，河口用分汊辨认。统一左上方照明，所有设施短影向右下。只在高地、近岸及河口局部增加刻线，缩小后仍以陆海轮廓为先。

## 视觉与节点

| 用途 | A1 起始色 |
| --- | --- |
| 海面与页面深底 | `#101820` |
| 主陆石墨蓝灰 | `#304149` |
| 档案纸面与地图亮字 | `#E5E9E7` |
| 档案墨色 | `#15262D` |
| 选择与焦点的冷青 | `#90C4C8` |
| 沙金参考色 | `#B8A487`，用于少量浅滩或锚点基座 |

海岸、坡面和等高线从海陆底色派生，用面与线的明度差表现地形。全页只有一个亮面板。地图字体左对齐，地图区名 12–14 px，卡片正文 15–16 px，标题 24–28 px。正文、项目名与操作统一用站点系统无衬线，英文 WORKS 标题可复用现有 Oxanium 600。文字与背景至少 4.5:1，可操作轮廓和焦点至少 3:1，选中及焦点同时用形状与描边区分。

每个节点有同向短影、低矮底座、短立柱或架体和顶部单色图形。平台采用宽台面，系统采用窄塔，视觉计算使用开口或错位薄面，出版使用层叠体。四种基本轮廓共享倒角、描边、光向与基座规则。公开项目标识可在获准后适配单色顶标，A1 先用原创几何。桌面默认显示四个锚点的名称，其他节点在悬停、键盘聚焦或选中时显示名称。窄视口默认保留设施轮廓，名称让位于选中提示和卡片。所有按钮始终有完整的无障碍名称。

## 版式与状态

桌面页首只有站点导航、WORKS 标题和「项目索引」。总览时地图居中占主面积。内容区宽度达到约 900 px 时，卡片与索引在右侧共用约 340–380 px 的位置，地图适配剩余宽度并保持全图可见。单列时选中卡片在地图之后，索引打开时在工具条与地图之间。移动端沿用同一画布与坐标，等比完整显示，页面原生竖向滚动。

| 状态 | 画面和操作 |
| --- | --- |
| **Overview · 总览** | 首次进入展示完整地图，八个项目均可操作。点击节点或用 Enter / Space 激活即选中。地图空白处不承担关闭或导航动作。 |
| **Hover / Focus · 提示** | 细指针悬停或键盘聚焦时仅加强节点边缘并显示项目名。离开即还原。触屏第一次点击直接选中。焦点提示可独立于当前选中，且不会替换卡片。 |
| **Selected · 选中** | 节点显示冷青色底座描边，所在区域局部提亮，其他节点适度退后且保持可操作。全图仍在视口中。桌面可朝选中位置轻微重构图，位移至多 12 px，若可能裁切节点就保持位置。切换节点直接更新同一张卡，再点已选节点保持打开。 |
| **Index Open · 索引** | 「项目索引」在同一面板位置展开，按四类显示全部八条，条目包含项目名、分类和同一条简介。打开期间记住当前选中项目并暂时收起卡片。选择条目关闭索引、聚焦地图并打开新卡，取消时恢复打开前的卡片或总览。 |

卡片是带标题的非模态区域。激活项目后把焦点送至卡片标题，窄屏仅在标题不在视口内时用最近距离带入视野。卡片与索引都有可见关闭按钮。Escape 关闭当前面板，取消索引时焦点返回索引按钮，关闭卡片时回到当前节点。索引按钮用 `aria-expanded`，打开后焦点进入索引标题，再按同一按钮可关闭。节点用真实按钮和清楚的选中状态。Tab 顺序稳定，按索引组及组内顺序走完八个节点，面板打开时保持原生焦点移动与滚动。

卡片按「项目名 / 关闭 → 分类及状态 → 一句简介 → 主入口 → 一张预览」组织，允许一个有实际用途的第二链接。冷白实体底、深字、一处切角和一条细分隔线表达档案终端。预览优先使用核准的真实静帧，标注内容与来源，预留固定 16:9。缺图时保留同尺寸的设施线稿，标注「项目标识」，入口与简介照常可用。卡片不内嵌运行中的项目。

动效由操作触发。节点回应约 120–160 ms，面板可用约 180–220 ms 的短位移和淡入，所有切换立即更新内容与焦点。减少动态效果下直接切换。保持地图静止，无背景循环、扫光、折射滤镜或独立音效。

## A1 实现与 A2 边界

1. 用手绘 SVG `viewBox="0 0 1000 700"` 先落实轮廓、河道、地形明暗和三种线条。地形与设施轮廓按同一画布坐标布局，SVG 作为装饰层。节点使用同一比例矩形里的 HTML 按钮覆盖，坐标从数据换算为百分比。保留至少 44×44 CSS px 触控区。在 320 px 窄屏给地图至少 288 px 内容宽度，先验证八点及焦点框是否相撞，再增加标签。图层绘制采用静态 SVG，面板采用 CSS Modules。
2. 一份静态项目清单提供 `slug`、名称、分类、区域 ID、锚点、标识、简介、状态、入口和预览。地图地貌独立于内容。React 只管理选中 slug 和索引开关，悬停及键盘焦点用 CSS。所有项目从同一份数据进入地图、卡片与索引。增加项目通常只需加一条记录和一个坐标，先使用现有地区内的空地。
3. 原型包括八个可操作节点、四种状态和浅色卡片。渲染失败或脚本关闭时仍显示静态 HTML 项目索引、简介和真实入口链接。A1 在 1440×900、390×844 和 320 px 宽度验证地图是否完整、八个项目是否均可选、卡片是否遮挡节点，以及触屏、键盘、Escape 和减少动态效果下的行为。用总览、Sofaraway 选中、GopherAtlas 索引跳转三组画面评审空间辨识度。
4. `/works` 是总览入口。A1 选择仅为页内状态，不改浏览器历史。稳定 slug 供 A2 的 `/works/[slug]` 复用，详情可按项目清单静态生成。项目卡只提供实际存在的链接。A2 再核准真实预览和独立站点、打磨上线内容。
