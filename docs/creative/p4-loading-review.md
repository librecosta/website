# WEB-V0.1-P4 加载验收

## WORLD

按原型复现浅灰绿全屏背景、中央标记与 12 段进度条。内圈采用等长、等距的整圈虚线。WebGL 初始化、首屏遗迹资产就绪、首帧成功提交分别推进至第 3、7、12 段。等待资源时使用不确定状态，音频不阻塞揭示。

Chrome 在 1440×900 实测加载层淡出约 559 ms。模拟 GLB 请求失败、WebGL 2 不可用、上下文丢失及着色器链接失败时，均进入原有降级界面。重新加载和禁用 JavaScript 的静态阅读也完成了检查。

## WORKS

旧实现中预览和 Canvas 同时改变透明度，重叠处在两层都为半透明时仍会露出深色底。现在仅 Canvas 淡入，预览保持完全不透明，等过渡结束再隐藏。切换相邻项目时，旧画面保留到目标预览解码完成。

逐个打开八座岛屿，共采样 383 个淡入中间帧，预览始终保持不透明。轮盘首屏无 GLB 请求或 WebGL 上下文，单岛阶段最多一个活动上下文，退出后归零。测试还覆盖快速连续切换、加载中返回、模型失败、上下文丢失与重新打开。

## 验证环境

- `pnpm check`、`pnpm build:cn`、`pnpm build:intl` 均通过。
- Chrome 检查 CN 与 INTL 静态输出，覆盖 1920×1080、1440×900、960×720、390×844、320×568，以及六语言、键盘焦点和 Reduced Motion。移动尺寸为浏览器模拟。
- 验证正常网络、网络节流和缓存命中。缓存测试通过本地代理为验证资源设置缓存策略，缓存命中时资源传输大小为 0。
