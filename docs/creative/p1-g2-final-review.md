# The Expanse · G2 最终验收

**G2 完成。** 以本地 `develop` 的 G2-D 提交 `fcfa492` 为基准。固定机位、材质契约和交互复核均通过，本轮只记录验收结果。

## 材质与构造

| 阶段 | 验收结论 |
| --- | --- |
| G2-A | 五种低饱和材质语义成立。浅色 Satin Alloy、深色 Structural Iron 和 Precision Metal 分别对应外壳、承重件和接触面。Deck Composite 用于平台，Sand-Aged Surface 保留在易积沙的位置。发光由独立的 `cityMark` 控制。[材质规范](p1-g2-a-city-materials.md) |
| G2-B | 轴塔翼壳、内骨架、转接件与六类建筑共享材料分工。S3/S4 能读到轴塔中段的深槽、外围低台和内圈高塔，塔脚接缝在低雾中较淡。六类楼体仍批量实例化。[轴塔与街区](p1-g2-b-spire-and-districts.md) |
| G2-C | 主副环的浅壳、暗腹和冷灰导向面一致，截面和支座仍有明确主次。主环 M1/M2/M3 与泊位在不同旋转相位可辨。两处空港同用斜向承重根、复合甲板和铁质腹体，甲板小分缝和舱口从低机位或窄视口较难分辨。多相位画面和几何复核支持保留现有细节密度。[双环与空港](p1-g2-c-rings-and-skyports.md) |
| G2-D | 近景信号塔以偏暖的磨蚀壳体接入沙地，天线保留偏冷的金属响应，暗槽和沙埋线在 S2 关风沙时清楚。S1 右坡宽细纹有疏密变化，背风面更平缓。采样画面未见异常镜面反光或成片高频噪声。[荒原与风成表面](p1-g2-d-ruins-and-aeolian-surface.md) |

桌面 1440×900 复拍 S0–S5，移动档 390×844 复拍 S0/S2/S4/S5，DPR 均为 1。S1/S2 同机位另存关风沙对照。S0 的城市远影仍融入荒原，S4 的轴塔与主环主导构图。两档 S5 的品牌三部分全显且背景清楚。画面及采集前后的相机和时钟在 `.local/p1-g2-e/`，同一 G2-D 运行时代码作为本轮起点和验收结果。[G0 固定机位](p1-g0-visual-baseline.md)

## 技术与性能

- `pnpm check` 通过世界约束、类型检查和静态构建。每档 15 个 WebGL 程序链接成功，WebGL 错误为 0。合并几何、建筑和交通实例、飞艇及卫星的顶点属性长度、值域与逐面材质一致性通过检查。街区保留 6 个批次、118 个实例。资源释放路径与换档实测一致，桌面和移动来回切换后均稳定在 27 个驻留几何、6 个纹理。
- 两档的五个观察标记均打开对应卡片，可按 Escape 关闭。环与飞艇标记随目标移动，卡片保持各自的世界坐标。S3 的三个相位和几何复核确认主副环按 180 s / 155 s 反向运动，客运飞艇随泊位转动，货运飞艇保持巡航净空。原生滚动往返恢复开场机位，减少动态模式冻结城市时钟、切到静态沙面并提供可读文本。

Windows Chromium 157，AMD Radeon / ANGLE D3D11。正常风沙下每个固定机位采集 6 s，GPU 查询与实际帧间隔分开统计。以下为各轮分位数范围，单位 ms。桌面 G2-E 有四轮 S1/S2，移动有两轮。所有 GPU 窗口均无 disjoint。

## 保留问题与 G3 交接

- **S1 投影边缘。** 保留信号塔的真实落影。G3 从光源和阴影采样检查硬边，继续用 S1 正常与关风沙对照验证。[G2-D 成因验证](p1-g2-d-ruins-and-aeolian-surface.md)
- **大气层次。** S0–S2 风幕削弱远城明暗差，S3/S4 低雾减弱塔脚与台地分离。G3 可分开复核高仰角风幕和低处雾层，同时保留 S5 品牌背景的可读性。沿 S3 多相位继续看货运飞艇与街区车流的空间分层。
- **工程记录。** Chromium 仍报告 R3F 使用 `THREE.Clock` 的弃用警告。两档 Shader 和交互验收均通过。
