# The Expanse · G3-C 城市运动与空间纵深

直接对比 `a584908` 的 [G3-B 完成态](p1-g3-b-lighting.md)。本轮调整两条车道的空间关系、移动档车流灯点和城市时钟的暂停行为。巨构、空港、两艘飞艇的路线与停靠关系、G3-A 大气及 G3-B 照明继续沿用。

## 巨环、卫星和飞艇

- **主副环与卫星。** 主环正转 180 s、副环反转 155 s、卫星绕行 60 s，原有共享倾斜和慢摆保留。离线采样 0–900 s，并检查各周期边界前后 1 ms 的姿态；各自转周期闭合，公共父级姿态继续随时间变化。两环在父坐标系中有 417 个城市局部单位的垂直净空，和建筑的扫掠范围未发现穿插。浏览器四个相位中，轴塔依次被近侧环梁和空港遮挡，断口、M3 短弧和副环仍可分辨，未观察到高光异常跳变。
- **客运飞艇。** 飞艇、泊位与观测锚点共用主环父变换。两条滑橇的六个射线探测点均与真实甲板面重合。S3 在 2.4、26.8 和 60 s 的世界坐标与离线变换吻合；前两次标记随船移位，60 s 的标记被结构正确遮挡。60 s 画面能从侧面看到飞艇与泊位的接触。
- **货运飞艇。** 保留原闭合路线和速度 35，约 147.5 s 一圈。航向仍由曲线切线决定，离线步进 50 ms 的最大姿态变化约 0.54°，含闭合接缝。保守船体包围盒与主副环、建筑、卫星、停靠艇和车流未发现重叠。144.7 s 附近主环最接近；将这一段加密到 0.01 s 并在 S4 复拍，仍未发现穿插。此处是近距复验点，包围盒结果不代表真实船壳的精确最小距离。

## 时钟与真实画面

城市时钟继续由 `FutureCity` 持有，双环、卫星、飞艇和实例车流都读这一份时间。减少动态模式锁定当前相位；初次以减少动态加载时从 0 静止。隐藏或减少动态期间暂停计时，恢复首帧不计入暂停间隔。正常终景停留、回滚再进入终景及桌面切换移动档均未见相位重置。模拟隐藏时 `1.001 s` 保持不变，恢复首帧仍为 `1.001 s`。WebGL2 不可用时保留 HTML 回退。

按 [G0 机位](p1-g0-visual-baseline.md) 在真实浏览器复拍：桌面 1440×900，移动档 390×844，DPR 均为 1。S3/S4 的前后图均取城市时间 2.4、10.5、26.8、60 s，桌面 S5 另取 10.5、60 s，移动 S4/S5 分别取 26.8、60 s。定相只用于本地截图；性能和交互使用正常运行的时钟与风沙。S3/S4 的中层与快线更易区分，S5 的品牌文字仍清晰。移动远景保留大构件轮廓，最小载具在 DPR 1 仍可能随像素覆盖变化。全幅、截图元数据、相位、净空和原始性能记录在 `.local/p1-g3-c/`。
