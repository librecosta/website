# WORKS · 三维全息作品地图

`/works` 以固定俯视角呈现一座虚构的海岸城市和周边岛屿。街区沿低地与海岸展开，山岭由等高线表达，海湾渡线接入岛上道路。地表、岸壁、建筑、项目球和投影环由 Three.js 实时渲染。地图与第一幕各自管理场景和资源，`/works` 继续静态导出。

滚轮围绕指针缩放，拖动平移，窄屏使用斜向取景。缩放按钮支持键盘操作，点击百分比恢复总览。玻璃球内嵌图形随相机投影，球旁的简介在悬停或键盘聚焦时显示。点击进入透光详情，索引可定位到视野外的项目。WebGL 初始化失败时仍有 HTML 作品入口。

本轮使用六项已有作品的一句话简介。GoFurry 使用项目图形，其余项目使用本站为沙盘绘制的图形标识。[项目数据](../../src/components/works/projects.ts) · [地图几何](../../src/components/works/works-world.ts) · [素材来源](../../public/works/asset-notices.txt)

## 验证

- `pnpm check` 通过，Chromium 生产预览未报告 WebGL 或控制台错误。
- 1440×900 验证滚轮缩放、鼠标拖拽、恢复总览、键盘聚焦简介、六张详情、索引定位和 Escape 焦点恢复。
- 390×844 与 320×568 的总览均有六个互不重叠的 44×44 CSS px 点击区。短屏详情保留所选项目球。真机触摸与双指缩放尚未实测。
- 总览、放大、详情和移动视口截图见本地 `.local/works/3d-*`。
