# 静默巨碑四面展开 · P1-C1A4-B

打开 `/lab/monument-surface`，也可从 `/lab/expanse?debug=1` 进入。图板可切换四面展开、单层拆解、四个三维折角。导出按钮提供可编辑的合成 SVG、同坐标透明图层，以及黑底白线的发光遮罩。

## 展开与折合

按碑体外侧观察的顺序展开正、右、背、左四面。只有左面外缘回接正面处开缝。展开使用原网格的斜高、各面实际边长与同一折边的刚性旋转。1 SVG 单位对应 1 场景单位，网页显示随视口缩放。碑体基宽、高、基深为 `920 × 2400 × 560`。顶底、槽内与倒角保留基材，两个槽口按网格的倒角内边界精确裁切。

跨角接合带位于离底 `28.6%–31.2%` 的同一高度，实际落在裸露碑身的下段。主槽及折返辅槽打断平面纹样，折角两侧的带线仍可对齐，倒角露出一线基材。正面用主槽上方的桥接建立轴线，右面把低位支线转接到肩部，背面留下最大的封合面，左面以高低不同的接点回接。图例中的功能名称用于解释构图关系，属于设计标注。

| 图层 | 作用 |
| --- | --- |
| 主分区 | 用低反差暖灰面、槽口上方的封装面和同高接合带交代结构分段。 |
| 主纹刻 | 用少量长线、错台和槽冠桥接建立骨架，线条保持平面。 |
| 次级连接 | 从接合带向面域和主线转接，各面按不同节奏保留空白。 |
| 精细符线 | 只在端点与对位节点留刻度和暖白短线。可单独导出为线性发光遮罩。 |

## 源与验收

`layout.ts` 保存人工落点，`unwrap.ts` 从主碑网格推导等距立面，`artwork.ts` 输出同一坐标下的 SVG。三维预览把同一图稿贴回实际外立面三角形，用独立遮罩显示微弱暖白发光。倒角与槽壁沿用网格自身的受光。预览采用独立灯光，现行荒原场景继续用既有灰模。

`pnpm check` 核对展开前后的边长与对角线、折边接合带、闭合接缝、槽口面积和网格三角形归属，并执行静态导出。后续可沿用这套展开坐标标定正式粗糙度和发光，再在荒原实际机位评估亮度。
