# 第一幕：The Expanse — 荒原

## 已确认方向

- 苍白荒漠，具有风蚀与矿物质感。
- 首屏辽阔、安静，具有巨大的空间纵深；远处只显露少量朦胧、尺度惊人的倾斜轮廓。
- 前景清晰，中景具有结构层次，远景被空气透视与光线逐渐吞没。
- 巨构具有精密秩序与宏伟尺度，其共同性来自比例与结构语言，而非复制同一建筑。
- 镜头从远眺逐渐加速逼近，随后穿越巨构群，在外围门槛停下。
- 运动由滚动进度驱动，可逆，具有适度惯性；用户能够停止、继续和反向探索。
- 可采用曲线路径、俯仰、倾斜及有限滚转，不强制 S 形。
- 首屏极简，仅保留 LibreCosta、轻微滚动提示和底部细进度线。

## P1-A4 空间语法 · 埋藏、失序与静默

- 苍白荒原中的构件被地貌与时间逐渐吞没。半埋、斜插和只露出切面的状态优先于完整竖立的建筑；必须由真实地形遮挡形成埋藏。
- **Basin Remnants**：左右各一组几乎完全埋没的精密结构局部。左侧只露长残缘，右侧以两段具有同一朝向关系的切面回应；不摆完整大方块、立柱或随机碎石，谷道中央保持开阔。露出量以镜头评审为准。
- **Broken Alignment**：以人工设计的理想布局为基础，另外记录受限的偏移、沉降和旋转。当前试算为三块纵深错位的巨板，左右交错、比例不同；保留原有两柱的外倾关系，第三块斜板承担短暂遮挡。共同性来自基准与切割语言，不追求对称或复制森林。
- **The Still Monolith · 静默巨柱**：沿用原中央主体，放大为明显超越中景的近乎绝对竖直厚重巨构。只保留一道深窄纵向凹槽；凹槽有实际内壁与后壁，并止于顶部以下，保持单一完整顶冠。基础灰材质，无黑线贴片或装饰性结构。
- 只以少量主角建立视觉重点，次级残段与远景轮廓服从留白、遮挡和空间节奏。宁可删除构件，不以数量制造文明感。
- 地形由 **Valley Spine**（谷地中轴）、**Basin Profile**（低中间、高两侧）、连续坡脊、交叠丘面及 **Path Mask**（柔化通道）组织。连接沙体不能在每个丘包之间衰减回谷底；左侧丘面重叠接壤，仍保留前后层次。种子只控制细节，不决定视觉重点。
- 地貌包裹巨板。浅谷保持低缓、宽阔，不发展为高山峡谷，不以细碎噪声替代大尺度形体。
- 首个滚动立即有位移；依次经历浅谷远眺、接近列阵、斜板真实遮挡、绕出后再次揭示、减速抵达。遮挡来自几何与连续路径，不改变对象显隐；结尾允许裁掉巨柱顶部，用低视点与前方凹槽表现巨大尺度。
- 终点只保留静默巨柱，不恢复旧双门板或添加第二个主角。当前名称是第一幕布景目标，不补充其制造者、用途或文明来源。
- 原生页面滚动连续控制旅程；短暂的进度追随可以平滑输入，但停止后必须收敛，不自动继续飞行。允许小幅俯仰、转向与有限滚转；相机只由一个系统写入。
- 正常画面为全屏空间，原生滚动条只隐藏外观；底部进度线直接反映页面滚动，独立于相机的有限平滑。调试功能不属于正常界面。减少动态效果时保留可读的静态观览。
- 响应式以保住整体空间关系为先：按参考画幅 contain 取景，缩窄视窗时整体缩小，不能固定垂直视角后直接裁掉两侧。竖屏的主体占比会随之减小，不用改动路径伪装成同一构图。

## 后续沙暴条件 · 仅设计方向

未来可让浅谷风沙明显、列阵周边紊乱、静默巨柱附近逐渐平静，远处沙暴持续存在。本轮只保留此方向，沿用基础 Fog；不实现粒子、风场、沙暴 Shader、体积雾或未使用的抽象层。不添加石堆、枯枝或生物点缀。
