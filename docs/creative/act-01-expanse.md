# 第一幕：The Expanse — 荒原

## 已确认方向

- 苍白荒漠，具有风蚀与矿物质感。
- 首屏辽阔、安静，具有巨大的空间纵深；远处只显露少量朦胧、尺度惊人的倾斜轮廓。
- 前景清晰，中景具有结构层次，远景被空气透视与光线逐渐吞没。
- 巨构具有精密秩序与宏伟尺度，其共同性来自比例与结构语言，而非复制同一建筑。
- 镜头从远眺逐渐加速逼近，随后穿越巨构群，在外围门槛停下。
- 运动由滚动进度驱动，可逆，具有适度惯性；用户能够停止、继续和反向探索。
- 可采用曲线路径、俯仰、倾斜及有限滚转，不强制 S 形。
- 首屏极简，仅保留 LibreCosta、轻微滚动提示和底部细进度线。

## P1-A4 空间语法 · 反馈修订：残缘、碑林与主碑

- 苍白荒原中的构件被地貌与时间逐渐吞没。半埋、斜插和只露出切面的状态优先于完整竖立的建筑；必须由真实地形遮挡形成埋藏。
- **Basin Remnants**：左侧横卧在坡脚，朝谷道露出低矮的端面和窄顶面；右侧遗构内倾，仅露出局部斜切面。谷道中央保持开阔，露出量以镜头评审为准。
- **Broken Alignment**：以人工设计的理想布局为基础，另外记录受限的偏移、沉降和旋转。保留两块纵深错位、向谷外倾斜的巨板，比例和埋深不同；删除中央遮挡板，恢复通向主碑的清晰负空间。共同性来自基准与切割语言，不追求对称或复制森林。
- **The Still Monolith · 静默巨碑**：沿用原中央主体，改为克制的收分台体，底宽顶窄、中轴竖直，保持完整顶冠与一道真实深窄纵槽。它仍是最主要的目的地，不补充制造者、用途或文明来源。基础灰材质，无黑线贴片或装饰性结构。
- **Distant Stelae · 远方碑林**：与主碑共用收分几何，沿左右两侧分段向极远处延续。宽碑标记一段的起伏，细碑相互呼应，组间留下更长的空白。中段只读到细小、低对比的残影；终点仍与主碑相隔很远，右侧被现有沙坡遮去更多。
- 只以少量主角建立视觉重点，次级残段与远景轮廓服从留白、遮挡和空间节奏。宁可删除构件，不以数量制造文明感。
- 地形由 **Valley Spine**（谷地中轴）、**Basin Profile**（低中间、高两侧）、连续坡脊、交叠丘面及 **Path Mask**（柔化通道）组织。连接沙体不能在每个丘包之间衰减回谷底；左侧丘面重叠接壤，仍保留前后层次。种子只控制细节，不决定视觉重点。
- 地貌包裹巨板。浅谷保持低缓、宽阔，不发展为高山峡谷，不以细碎噪声替代大尺度形体。
- 首个滚动立即有位移；沿浅谷接近双板，中景可见很远的碑林，终段减速、抬高视线。取消首轮刻意遮住主体的镜头，结尾保持观览距离，以低视点仰望完整主碑，四周留有画幅余量。
- 主碑保持唯一的视觉终点，碑林服从远近层级；不恢复旧双门板或添加第二个主角。当前名称和试算参数属于布景研究，不冻结世界观事实。
- 原生页面滚动连续控制旅程；短暂的进度追随可以平滑输入，但停止后必须收敛，不自动继续飞行。允许小幅俯仰、转向与有限滚转；相机只由一个系统写入。
- 正常画面为全屏空间，原生滚动条只隐藏外观；底部进度线直接反映页面滚动，独立于相机的有限平滑。调试功能不属于正常界面。减少动态效果时保留可读的静态观览。
- 响应式以保住整体空间关系为先：按参考画幅 contain 取景，缩窄视窗时整体缩小，不能固定垂直视角后直接裁掉两侧。竖屏的主体占比会随之减小，不用改动路径伪装成同一构图。

## 已冻结的制作顺序

1. 确立浅谷、巨构层级与滚动构图（P1-A4）。
2. 确立基础地貌、日照与空气透视（P1-B1）。
3. 用真实几何建立风成沙丘，先验收迎风坡、背风坡和谷道，再加入静态风纹（P1-B2R）。
4. 在相同机位收敛风纹强度，并以 WebGL2 实测建立性能基线（P1-B2R2）。
5. 用低位侧光、浅冷天空和暖白地平线确立光影与空气透视（P1-B3）。

沙丘轮廓与整体受光决定画面层次，沙纹只在合适的距离补足细沙质感。P1-B2 的硬壳路线保留为研究对照。

P1-B3 选用雕塑感侧光作为当前基线：首屏保留明亮留白，进入谷地后读得出沙脊的明暗两面，终点主碑保有亮侧面、暗正面和清楚的深槽。碑林沿着暖白地平线逐渐隐去。柔光方案留在调试模式中，供相同机位复看；本轮配置不是最终天气或材质定案。

## 后续沙暴条件 · 仅设计方向

未来可让浅谷风沙明显、列阵周边紊乱、静默巨碑附近逐渐平静，远处沙暴持续存在。本轮只保留此方向，沿用基础 Fog；不实现粒子、风场、沙暴 Shader、体积雾或未使用的抽象层。不添加石堆、枯枝或生物点缀。

世界观与后续叙事不变。本轮只研究第一幕空间与滚动体验，不进入正式材质或后续世界。
