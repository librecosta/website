# 第一幕：The Expanse — 荒原

## 已确认方向

- 苍白荒漠，具有风蚀与矿物质感。
- 首屏辽阔、安静，具有巨大的空间纵深；远处只显露少量朦胧、尺度惊人的倾斜轮廓。
- 前景清晰，中景具有结构层次，远景被空气透视与光线逐渐吞没。
- 巨构具有精密秩序与宏伟尺度，其共同性来自比例与结构语言，而非复制同一建筑。
- 镜头从远眺逐渐加速逼近，随后穿越巨构群，在外围门槛停下。
- 运动由滚动进度驱动，可逆，具有适度惯性；用户能够停止、继续和反向探索。
- 可采用曲线路径、俯仰、倾斜及有限滚转，不强制 S 形。
- 首屏极简，仅保留必要的品牌识别和交互提示。

## P1-A2 空间语法

- 苍白荒原中的构件被地貌与时间逐渐吞没。半埋、斜插和只露出切面的状态优先于完整竖立的建筑；必须由真实地形遮挡形成埋藏。
- 家族收敛为 **Monolith**（厚重巨板／巨柱）、**Buried Structure**（半埋横梁／楔段／切面）和 **Threshold**（终点入口或负空间）。不构建城市、柱林或重复 prefab 展示阵列。
- 只以少量主角建立视觉重点，次级残段与远景轮廓服从留白、遮挡和空间节奏。宁可删除构件，不以数量制造文明感。
- Terrain Massing 人工决定大尺度地貌与通道；Terrain Detail 只作克制扰动。埋深和朝向分别可调，主角位置明确指定，种子不决定视觉重点。
- 巨板与沙丘相互包裹。先远眺，靠近后揭示低矮残段，再穿过稀疏结构场，稳定停在巨大的门槛之外。本轮样机以两座相互呼应的斜板围出门槛，不使用完整矩形门框。
- 原生页面滚动连续控制旅程；短暂的进度追随可以平滑输入，但停止后必须收敛，不自动继续飞行。允许小幅俯仰、转向与有限滚转；相机只由一个系统写入。
- 正常画面为全屏空间，仅留 LibreCosta 与轻微滚动提示；调试功能不属于正式界面。减少动态效果时保留可读的静态观览。
