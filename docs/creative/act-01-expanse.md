# 第一幕：The Expanse — 荒原

## 已确认方向

- 苍白荒漠，具有风蚀与矿物质感。
- 首屏辽阔、安静，具有巨大的空间纵深；远处只显露少量朦胧、尺度惊人的倾斜轮廓。
- 前景清晰，中景具有结构层次，远景被空气透视与光线逐渐吞没。
- 巨构具有精密秩序与宏伟尺度，其共同性来自比例与结构语言，而非复制同一建筑。
- 镜头从远眺逐渐加速逼近，随后穿越巨构群，在外围门槛停下。
- 运动由滚动进度驱动，可逆，具有适度惯性；用户能够停止、继续和反向探索。
- 可采用曲线路径、俯仰、倾斜及有限滚转，不强制 S 形。
- 首屏极简，仅保留 LibreCosta、轻微滚动提示和底部细进度线。

## P1-A3 空间语法 · 浅谷推进

- 苍白荒原中的构件被地貌与时间逐渐吞没。半埋、斜插和只露出切面的状态优先于完整竖立的建筑；必须由真实地形遮挡形成埋藏。
- 四层按纵深分工：**Foreground Basin** 由左右坡体围住低缓通道；**Mid Fragments** 仅露出低矮残构；**Monolith Field** 以稀疏斜插巨板／巨柱建立秩序；**Hero Destination** 在远方抬出主体，随推进逐步显形。
- 构件职责为 **Foreground Debris**、**Mid Monoliths**、**Hero Structure**。前景不摆完整大型主角，残片不与远方主体争夺注意力；柱阵的倾角、比例和埋深有区别，不构建城市或复制体森林。
- 只以少量主角建立视觉重点，次级残段与远景轮廓服从留白、遮挡和空间节奏。宁可删除构件，不以数量制造文明感。
- 地形明确分成 **Valley Spine**（谷地中轴）、**Basin Profile**（低中间、高两侧）、**Dune Layers**（近／中／远丘脊）、**Path Mask**（柔化通道）与 **Burial Mask**（局部覆沙）。**Debris Distribution** 人工指定残片槽位。种子只控制细节，不决定视觉重点。
- 多层丘脊交错形成遮挡，地貌包裹巨板。浅谷保持低缓、宽阔，不发展为高山峡谷，不以细碎噪声替代大尺度形体。
- 节奏为 0–20% 静止远眺，20–45% 缓慢沿谷推进，45–75% 进入柱阵增强视差，75–100% 减速接近主体。没有离散分镜、吸附或自动播放。
- P1-A2 的近处宽巨板与终点双斜板布局已被本轮替代；当前远方高主体配一处半埋侧构，只验证目的地与纵深关系，不冻结最终入口造型。
- 原生页面滚动连续控制旅程；短暂的进度追随可以平滑输入，但停止后必须收敛，不自动继续飞行。允许小幅俯仰、转向与有限滚转；相机只由一个系统写入。
- 正常画面为全屏空间，原生滚动条只隐藏外观；底部进度线直接反映页面滚动，独立于相机的有限平滑。调试功能不属于正常界面。减少动态效果时保留可读的静态观览。
