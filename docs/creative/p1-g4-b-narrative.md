# The Expanse · P1-G4-B 字幕与品牌揭示

2026-11-13 基于 `develop` 的 G4-A `23297c9`。镜头与叙事触发继续共享原生滚动和既有平滑路径。

## 字幕触发与生命周期

- `ExpanseLab` 按稳定 ID `01`、`02`、`03` 记录本次访问已触发的独白。第一段在开始探索时触发，后两段沿用路径进度 `u=.55` 和 `u=.965`。正常前进等镜头跟上，跨过多个阈值时逐一入列。如果原生滚动已经越过阈值并在镜头跟上前反向，补发这次跨越的独白。
- `ExpanseNarrative` 让每段独白持有自己的 GSAP 时间轴。约 14 字/秒，保留换行和标点停顿。前两段打字完成后停留 2.5 秒，再淡出 0.42 秒。终句从打字完成到淡出结束共约 2 秒。各段在自己的淡出结束时移除，滚动方向与后续字幕均不改变生命周期。
- 字幕从同一区域底部向上堆叠，保留文案原有换行。旧段移除后，其余字幕随正常文档布局收拢。窄屏为进度栏预留空间，320 px 与短视口缩小字号及段距。逐字内容对辅助技术隐藏，每段仅在完整时向独立的 `role=status` 写入一次全文。

## 品牌触发

原生滚动达到既有旅程终点、平滑路径 `u≥.99995`、终句淡出完成且字幕组已清空时，才开始原有标题 → 说明 → 署名时间轴。触发点位于终点机位，终景停留区内无需额外滚动。已开始的揭示可容忍终点前 2 CSS px 的滚动抖动，该区间自身不能开始揭示。离开后反放，再抵达可继续播放品牌，独白仍只播放一次。隐藏的品牌保持 `inert` 与 `aria-hidden`。

## 浏览器验收

| 场景 | 结果 |
| --- | --- |
| 正常推进、开场直跳终点 | 三段按顺序触发，逐字完成并独立淡出。品牌在所有段落移除后才出现。 |
| 第一段打字中快滚至终点 | 三段同时在场，完整文案自上而下显示。采样中前两段打完后约 2.5 s 开始淡出，终句约 2.0 s 后移除。 |
| 快滚后立即回滚 | 镜头尚未跟到后段便回到开场，三个已跨越节点仍完成播放。再进终景只播放品牌。 |
| 95% 停留、终点边界 | `p=.95 / u=.96829` 停到字幕清空，品牌三个元素透明度均为 0。到终点后自动揭示。先抵达再退 1 px、并在字幕播完前留在该处，品牌仍隐藏。已揭示后 1–2 px 往返无重置。 |
| 布局 | 1440×900、390×844、320×568、1440×420 的三段纵向堆叠均无裁切、内部滚动条、进度条遮挡或品牌重叠。窄视口由桌面 Chromium 模拟。 |
| 音频、后台与降级 | 并行打字复用音频引擎 45 ms 全局节流。实测仅一个 AudioContext，关声后立即停止当前文字音效，余下字幕继续。模拟页面隐藏时文字时间轴暂停，恢复后从原字数续播。减少动态模式及模拟 WebGL2 不可用均可阅读完整 Transcript。刷新后可重新触发独白。 |

单段移除只清理自己的 GSAP 上下文。文字音效由叙事层在隐藏、退出动态模式或卸载时统一停止，关闭音频继续由站点音频引擎处理。终景桌面计数与 G4-A 同为 25 Draw Calls / 364,612 Triangles，窄视口为 25 / 154,700。`pnpm check` 已通过世界检查、类型检查和静态构建。

全幅截图、逐帧字幕/品牌状态、音频探测及构建日志在 `.local/p1-g4-b/`。
